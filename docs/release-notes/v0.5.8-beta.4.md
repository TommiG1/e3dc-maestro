# v0.5.8-beta.4: Einrichtungsfehler bei älterem Home Assistant behoben

> **Beta.** Enthält alles aus 0.5.8-beta.3. In HACS Beta-Versionen anzeigen.

## Korrekturen

- **Einrichtungsfehler „unexpected keyword argument config_entry_id“.** Wenn hacs-e3dc Anlagen-Entities deaktiviert hat, legt Maestro eine Reparatur-Meldung an. Dabei wurde ein Parameter übergeben, den nicht jede Home-Assistant-Version kennt, und die Einrichtung brach ab. Maestro prüft das jetzt vorher. Schlägt die Meldung trotzdem fehl, läuft die Einrichtung weiter.

## Update

1. HACS: E3DC Maestro auf **0.5.8-beta.4** (Beta-Versionen anzeigen).
2. Home Assistant neu starten.
