# v0.5.2-beta.3 – Debug herunterladen und voller Ringpuffer

> **Beta.** Enthält 0.5.2-beta.2. In HACS Beta-Versionen anzeigen.

Support-Dumps aus dem Cockpit und ein Debug-Ringpuffer, der auch bei stabilem Korridor gefüllt bleibt. Dazu schlankeres HACS-README und Issue-Vorlagen.

## Cockpit

- **Debug herunterladen** unter Entscheidung → Debug-Log: JSON-Support-Dump (Version, aktuelle Entscheidung, Ringpuffer, Optionen ohne Secrets) für GitHub-Issues.
- Debug-Ringpuffer: bei aktivem Debug-Schalter schreibt Maestro **jeden Regelungstakt** eine Zeile (nicht nur bei Limit-Änderungen); Einschalten loggt sofort „Debug-Logging aktiviert“.
- Hilfe (Entscheidung / System) beschreibt Button und Debug-Schalter.

## Dokumentation / Repo

- README (DE/EN) für den HACS-Storefront gestrafft; Handbuch-, Discussions- und Website-Badges.
- Issue-/PR-Vorlagen und Security-Hinweis.

## Hinweise

- **Neustart** von Home Assistant, damit der Websocket `e3dc_maestro/debug_dump` registriert ist
- Danach Browser **hart neu laden**, damit Panel und Hilfe ankommen
