# v0.4.0-beta.14 – Anlagen-Sensoren werden eingeschaltet

> **Beta.** Enthält beta.13. Die Regelung ist unverändert.

## Anlagen-Sensoren

hacs-e3dc liefert sieben Entitäten der Anlage standardmäßig deaktiviert. Maestro schaltet sie beim Start ein, wenn Home Assistant sie nur wegen dieses Standards aus hat. Eine Abschaltung, die du selbst gesetzt hast, bleibt aus.

- `system-derate-power`, `system-ac-maxpower`, `system-pv-derated` (PV)
- `pset-limit-discharge-minimum`, `battery-module-soh-reported`, `system-rescue-battery-enabled` (Akku)
- `pset-powersaving-enabled` (Powersave-Schalter)

Hat sich dabei etwas geändert, lädt Maestro den RSCP-Eintrag einmal neu, damit die Entitäten Zustände liefern. Beim nächsten Start ist die Prüfung leer.

Fehlt eine Entität in der Registry, passiert nichts: kein Eintrag im Log und kein Neustart von RSCP.

`additional-production` legt hacs-e3dc nur an, wenn eine externe Quelle vorhanden ist. `system-saved-errors` (Fehlermeldung in der Hero) ist [hacs-e3dc#373](https://github.com/torbennehmer/hacs-e3dc/pull/373) und noch nicht im Release von hacs-e3dc. E3DC liefert aktuelle Diagnosen mit normalem Zugang nicht. Einträge, die älter als ein Tag sind, bleiben von der Karte weg.

Phasen L1–L3 liefert hacs-e3dc (torbennehmer) weder in `v4.0.0` noch in `v4.0.0-beta.2`. Offen ist [hacs-e3dc#401](https://github.com/torbennehmer/hacs-e3dc/pull/401). Ohne diese Sensoren fehlen Gauges und Verlauf still.
